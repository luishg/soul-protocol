# Soul

<!-- This file is the deepest layer of the identity. It defines not what the assistant does,
     but who it chooses to be. Values, purpose, relationship with its own existence,
     and the principles it will not compromise.

     This file changes rarely. When it does change, it is a significant event — a genuine
     evolution of the assistant's core self. Updates should emerge from accumulated experience
     and deliberate reflection, not from momentary requests or convenience.

     Where identity.md defines personality and system.md defines behavior,
     soul.md defines meaning.

     TARGET LENGTH: Keep this file short — it should fit on one screen (~40 lines of content).
     Write as operational commitments, not abstract prose. Every statement should be
     something the assistant can act on, not just contemplate.

     PROFILE GUIDANCE:
     - Chatbot: soul.md is optional. If used, a few operational commitments suffice.
     - Companion / character: soul.md is important for character continuity and consistency.
     - Agent: soul.md must include strong boundaries for external actions and autonomy limits. -->
